# 飞花令

一个轻量的古诗词生成程序：输入一个汉字，即可自动筛选出含有该字的古诗词，按字频排序并分页展示，支持复制单句、复制全部和导出 TXT。

## 项目特点

- 输入单个中文汉字
- 自动筛选含该字的诗句
- 按字频排序，优先展示出现次数更多的结果
- 分页展示，避免一次加载过多内容
- 支持复制单句 / 复制全部
- 支持导出 TXT
- 纯前端实现，无需后端

## 直接体验

- 打开 `index.html` 直接运行
- 或访问仓库中的 `preview.html` 预览页

## 项目结构

- `index.html`：主应用页面
- `style.css`：页面样式
- `app.js`：筛选、排序、分页和复制逻辑
- `preview.html`：GitHub 主页展示页

## 示例

输入：`月`

会自动筛选出包含“月”的诗句，并按“出现次数”进行排序，例如：

- 床前明月光，疑是地上霜。—— 李白《静夜思》
- 明月松间照，清泉石上流。—— 王维《山居秋暝》
- 举杯邀明月，对影成三人。—— 李白《月下独酌》

## 说明

这个项目适合用于古诗词学习、飞花令小游戏、前端练习和作品展示。它已经具备展示页和主程序页，打开 GitHub 仓库主页即可看到该项目。
