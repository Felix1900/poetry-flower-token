# 飞花令

一个轻量的古诗词生成小工具：输入一个汉字，即可自动筛选出含有该字的古诗词，并去重生成最多 100 句。

## 功能特点

- 输入一个中文字符
- 自动过滤含该字的诗句
- 去重，确保不重复
- 最多生成 100 句
- 支持复制全部与导出 TXT
- 纯前端运行，无需后端

## 运行方式

1. 下载本仓库
2. 打开 `index.html`
3. 在输入框中输入一个字
4. 点击“生成诗句”

## 项目结构

- `index.html`：页面入口
- `style.css`：样式文件
- `app.js`：诗词筛选与生成逻辑
- `preview.html`：仓库首页预览页

## 适用场景

- 古诗词学习
- 飞花令小程序
- 趣味诗词挑战
- 前端练习项目

## 使用示例

输入：`月`

可能输出：

- 床前明月光，疑是地上霜。
- 明月松间照，清泉石上流。
- 举杯邀明月，对影成三人。

## 说明

本项目使用内置诗词样例，适合快速演示和前端练习；如果你希望接入更大规模真实诗词数据库，可以进一步扩展成 API 版本。
